🇬🇧 English Description

TECHNICAL BD SERVER is an offline Wi-Fi file server and file management system developed using the ESP32-C3 Super Mini.

The ESP32-C3 creates its own Wi-Fi access point, allowing users to connect directly from a smartphone, tablet, or computer. After connecting, users can access the web dashboard through a browser without requiring an internet connection.

Key Features

- Offline Wi-Fi web server
- Web-based file manager
- User account setup and login system
- Create and manage folders
- Create, edit, and save text documents
- Delete Box with file restoration
- Permanent file and folder deletion
- Light and Dark themes
- Custom accent color
- Password change option
- JSON data backup
- Storage information
- LittleFS-based persistent storage

Hardware Used

- ESP32-C3 Super Mini

Project Purpose

The main purpose of this project is to demonstrate how an ESP32-C3 can be used to create a small personal offline file server with a browser-based interface.

No external hosting service or internet connection is required for normal local operation.

🇧🇩 বাংলা বিবরণ

TECHNICAL BD SERVER হলো ESP32-C3 Super Mini ব্যবহার করে তৈরি একটি অফলাইন Wi-Fi ফাইল সার্ভার এবং ফাইল ম্যানেজমেন্ট সিস্টেম।

এই প্রজেক্টে ESP32-C3 নিজেই একটি Wi-Fi Hotspot তৈরি করে। ব্যবহারকারী মোবাইল, ট্যাবলেট অথবা কম্পিউটার থেকে সেই Wi-Fi নেটওয়ার্কে কানেক্ট করে ব্রাউজারের মাধ্যমে ফাইল ম্যানেজমেন্ট ড্যাশবোর্ড ব্যবহার করতে পারবেন।

এই সিস্টেমটি ব্যবহার করার জন্য কোনো ইন্টারনেট সংযোগের প্রয়োজন নেই।

⚠️ Important Notes | গুরুত্বপূর্ণ তথ্য

- This project uses local HTTP communication, not HTTPS.
- Storage capacity depends on the ESP32-C3 LittleFS partition configuration.
- Always keep a backup of important data before uploading modified firmware.
- এই প্রজেক্টটি মূলত লোকাল নেটওয়ার্কে ব্যবহারের জন্য তৈরি।
- গুরুত্বপূর্ণ ডেটা সংরক্ষণের জন্য নিয়মিত Backup রাখুন।
